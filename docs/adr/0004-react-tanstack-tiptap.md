# React, TanStack Table und TipTap als UI-Basis

UI mit React + TypeScript. Das LV-Grid basiert auf TanStack Table mit Virtualisierung und eigener Baum-/Editierlogik (AG Grid verworfen: Tree Data nur in der Enterprise-Lizenz, nicht AGPL-kompatibel). Langtexte werden mit TipTap/ProseMirror und einem eingeschränkten Schema bearbeitet, das sich verlustfrei auf GAEB-Textstrukturen abbilden lässt.
