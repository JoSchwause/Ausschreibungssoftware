# Deutsche UI und deutsche Fachbezeichner im Code

Die UI ist deutsch. Im Code heißen Fachkonzepte wie im Glossar (`Leistungsverzeichnis`, `Position`, `Einheitspreis`, `Ordnungszahl`); technischer Code bleibt englisch (`render`, `store`, `useX`). Grund: AVA-Begriffe haben keine sauberen englischen Entsprechungen; Übersetzungen erzeugen Mehrdeutigkeit.
